# Barman Sacra

Web app mobile-first per consultare ricette cocktail durante il servizio.

## Stato
Prototipo Lite iniziale: ricerca, filtro categoria, schede con dosi e preparazione. Nessuna dipendenza dal bot Telegram o da API a pagamento.

## Origine dei dati
I ricettari completi sono conservati **solo** nel repository privato `ghooper74/edi-memory`, branch `barman-sacra`. Non copiare automaticamente materiale privato, fotografie, descrizioni protette, chiavi o token in questo repository pubblico.

Il prototipo contiene un piccolo campione di ricette revisionate manualmente. Le dosi vanno ulteriormente verificate prima di una distribuzione professionale.

## Avvio
Aprire `index.html` in un browser. La pagina è statica e può essere ospitata su GitHub Pages.

## Roadmap
1. Validazione tecnica e professionale del dataset distribuibile.
2. Ricerca per nome, alias e ingredienti, filtri e schede.
3. Test Android e accessibilità.
4. Solo successivamente: funzioni Premium con backend, autenticazione e controllo costi.

Principio: **Non inventare per stupire. Risolvi per servire.**
